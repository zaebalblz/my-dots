# Aura OS | Neural Interface
Это автономный интерактивный дашборд, созданный Gemini CLI.

## Функционал:
- **Задачи:** Управление ежедневными целями.
- **Таймер:** Система фокусировки 25:00.
- **Визуал:** Генеративный фон на WebGL.
- **Атмосфера:** Панель управления звуковым окружением.

## Как использовать:
Просто откройте `index.html` в браузере. Все данные сессии хранятся локально в коде (для этой версии).
